OSINT Metadata Extraction Tool

📌 Project Overview

This project is an Open Source Intelligence (OSINT) tool developed using Python to extract metadata from files.
Metadata analysis is an important technique in OSINT investigations because hidden information inside files can reveal useful insights such as creation date, author information, and device details.

The purpose of this project is to demonstrate how metadata can be extracted and analyzed using simple Python scripts.

---

🚀 Features

- Extract metadata from files
- Identify hidden information inside documents
- Simple Python-based implementation
- Useful for OSINT investigations and digital forensics learning

---

🛠️ Technologies Used

- Python 3
- OSINT Techniques
- File Metadata Analysis
